# ФАВОР-ГАРАНТ — редизайн сайта

Текущий сайт: https://favor-garant.ru/ (Tilda). Производитель металлоконструкций для городской среды: остановочные павильоны, рекламные конструкции, навигация, МАФ, оборудование для стрельбищ + услуги (дизайн-бюро, КБ, металлобработка, шеф-монтаж, экспертиза).

Задача клиента: по совету SEO-специалистов расширить каталог продукции. Клиент прислал примерный вариант меню — см. [brief/menu-draft.md](brief/menu-draft.md).
