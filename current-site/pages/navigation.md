Информационный пилон
Двусторонний пилон на опоре. Совмещает функцию указателя и рекламного носителя. Предназначен для размещения на остановках городского пассажирского транспорта
и внутри помещений.
узнать больше
Информационный указатель
Отдельностоящая конструкция из алюминиевых профилей и стального проката. Навигационный указатель служит для информирования о названиях городских улиц, объектов и их направлений.
Афишный стенд
Компактный рекламоноситель с каркасом из стальных труб. Предназначен для размещения на улице и внутри помещений.
Бренд стела
Отдельностоящая стела индивидуального дизайна изготовлена по брендбуку заказчика. Предназначена для установки на магистралях для информирования о местенахождении объекта.
Въездная стела
Отдельностоящая конструкция из профилированного металлопроката. Предназначена для размещения на въезде в город для информарирования о названии населенного пункта и его уникальности.
