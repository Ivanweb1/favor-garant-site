## 2. Описание компании
«ФАВОР-ГАРАНТ» — ведущий российский производитель металлоконструкций для благоустройства городской среды. Осуществляет комплекс услуг по проектированию, производству, дизайну, экспертизе и монтажу объектов для благоустройства городской инфраструктуры рекламоносителей, уличной мебели и других видов металлоконструкций.

## 4–5. Логотип
- Две версии: латиница «FG / FAVOR GARANT» и кириллица «ФГ / ФАВОР ГАРАНТ».
- Конфигурации: основной, сокращённый (только знак), в круге.
- Монохром: белый на тёмном и почти чёрный (RGB 6·6·7) на светлом.
- Охранное поле — ширина одного графического элемента (полоски знака).
- Мин. размер: печать 20 мм, web 194×66,5 px.
- Запрещены любые изменения формы, шрифта, пропорций.

## 7. Шрифты для web — Montserrat
- Montserrat Black + Bold — сочетание для названий продукции в заголовках (пример: «ОСТАНОВОЧНЫЙ ПАВИЛЬОН **«СТАНДАРТ»**»).
- Montserrat Black — заголовки и подзаголовки.
- Montserrat Bold — акценты в текстовых блоках.
- Montserrat Regular — основной текст.

## 8. Шрифты для печати — Manrope
ExtraBold — заголовки; Bold / SemiBold — подзаголовки и акценты; Medium / Regular / Light / ExtraLight — основной текст.

## 9. Фирменные элементы
- Паттерн из знака: основной (тёмный), облегчённый, светлый. Допускается поворот на 15° по часовой.
- Линейные иконки конструкций: модульные, рекламные, нестандартные, МАФ, остановочные павильоны, световые короба, тумбы.

## 10. Водяной знак
Белый `#FFFFFF`, прозрачность 20%, для защиты цифрового контента (пример — фото для Яндекс Справочника).

## 11. Фирменная продукция
Визитки, конверты A4/A5/C65, пакеты, папка A4, ручка, скотч — для сайта не критично.
